# a-stock-data 本地可视化工作台

当前网页只展示 `a-stock-data v3.7.1` 定义的数据能力。活动链路不读取旧的
`dashboard.json`、本地收盘动量模型或 Yahoo 日线，也不会用历史板块结果补齐失败端点。

## 一键启动

双击根目录的 `启动涨停雷达.cmd`，打开 `http://localhost:3000/`。停止时双击
`停止涨停雷达.cmd`。

启动脚本会：

1. 每60秒运行 `scripts/a_stock_data_snapshot.py`；
2. 把腾讯、东方财富、同花顺、财联社等 skill 端点结果写入
   `web/public/data/a-stock-data.json`；
3. 构建并启动网页；
4. 接口失败时在页面显示失败原因，不使用旧数据冒充实时结果。

## 页面功能

页面按决策顺序精简为三个工作区：

- **今日建议**：展示未触板潜力池、已触板强势池和参考价格计划，是最终研究结果层；
- **市场验证**：检查数据新鲜度、关键接口、行情字段、涨停价、大盘、板块联动和炸板风险，红灯时禁止生成新的9:35候选；
- **板块研究**：展示板块涨幅、上涨宽度、行业/概念资金和板块内备选，是候选的证据层，不是另一份推荐榜。

每个工作区均显示“看什么、有什么用、如何影响建议”。外部行情来自 `a-stock-data` 文档列出的公开端点；真实性闸门、评分、双池和价格计划属于本项目的本地确定性规则。公开财经端点不等同于交易所授权直连行情，红黄绿状态表示规则校验结果，不是数据真实性保证。

- 实时指数与ETF行情；
- 行业涨幅、行业/概念主力资金；
- 每个强势板块最多10只主板候选；
- 涨停池、炸板池、昨涨停表现；
- 任意6位代码实时行情与60日K线；
- 财联社电报、东方财富全球快讯；
- a-stock-data 能力目录与每个端点的更新时间、来源和健康状态。
- 9:35生成并冻结最多3只核心候选和2只观察备选；
- 每只候选展示参考关注区间、突破确认价、禁止追高价和结构失效价。
- 候选模块提供“未触板潜力”和“已触板强势”双池；封板股不提供排队追买提示，炸板股单列高风险回封观察。
- 未触板候选展示 T+1 参考止盈区间；所有新买仓位的卖出计划均从下一交易日起计算可执行性。

候选显示层沿用用户条件：沪深主板、非ST/退市、价格不高于35元；同时严格排除涨停池、炸板池、当前已涨停和当日曾触及涨停价的股票。潜在涨停候选还需在生成时距涨停不超过8%。
这只是数据研究工具，不构成投资建议或收益承诺。

## 9:35 每日研究候选

交易日9:35～9:40是唯一生成窗口。系统综合强势板块、腾讯实时行情、涨停/炸板情绪和开盘5分钟量价，达到门槛几只就展示几只，不为凑数强制补足5只。同一板块最多2只；名单生成后保存到`data/runtime/daily-pick-YYYYMMDD.json`，当日不重新排名，只更新现价和价格状态。

若关键数据源失败、服务器错过生成窗口或没有合格股票，页面会明确显示无候选，不沿用上一交易日结果。参考买入、止盈和失效价格是尚未完成充分样本外验证的规则区间，不是精确成交保证、上涨概率或个性化买卖建议。

## 手工命令

```powershell
# 单次刷新真实数据
.\scripts\mobile-refresh.ps1 -Once

# 启动网页（生产模式）
.\scripts\web.ps1

# 构建验证
cd web
npm run build
```

手机与电脑在同一局域网时，可访问 `http://电脑局域网IP:3000/` 并添加到主屏幕。
